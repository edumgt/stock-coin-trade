TEMPLATE

Lambda + HTTP API 연결

Events 아래 Type: HttpApi를 선언하면 SAM이 API Gateway와 Lambda 통합·호출 권한을 구성합니다.

member 경로를 이용한 최소 구조 예시
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Resources:
  DatabasePracticeFunction:
    Type: AWS::Serverless::Function
    Properties:
      CodeUri: ../lambda/member/
      Runtime: python3.11
      Handler: lambda_member.lambda_handler
      Timeout: 15
      Events:
        Api:
          Type: HttpApi
          Properties:
            Path: /members/{member_id}
            Method: GET
Outputs:
  ApiUrl:
    Value: !Sub "https://${ServerlessHttpApi}.execute-api.${AWS::Region}.${AWS::URLSuffix}"

02 · LOGS

Lambda 로그와 구성 확인

API Gateway의 5xx만 보지 말고 Lambda 로그, timeout, 메모리, VPC 연결을 함께 확인합니다.

운영 확인
sam logs --stack-name stock-coin-trade-member-practice \
  --name DatabasePracticeFunction --tail

aws lambda get-function-configuration \
  --function-name DatabasePracticeFunction

응답 판정

200 JSON 스키마 확인400 입력 검증 확인401/403 인증·권한 확인500/503 Lambda 로그·DB 경로 확인

API Gateway URL은 공개 진입점입니다. 회원 데이터나 쓰기 API는 JWT Authorizer·IAM·Cognito 등 인증을 추가하고, CORS 허용 출처와 메서드를 최소화합니다.
