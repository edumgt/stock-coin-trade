Korbit 공개 시세·호가 테스트

API Key 없이 Korbit 공개 시장 데이터를 서버 경유로 조회합니다. 주문·잔고·입출금 API는 호출하지 않습니다.

24시간 시세최근 24시간의 현재가, 등락률, 고가·저가, 거래량을 확인합니다.
호가 10단계현재 매수·매도 대기 주문의 가격과 수량을 각각 10단계까지 봅니다.
거래쌍은 btc_krw, eth_krw처럼 입력합니다. 공개 API에도 호출 제한이 있으므로 연속 클릭하지 마세요.
