/broker-api-test.html과 같은 조회를 수행하지만, App Key·Secret·계좌번호를 kb.key/kis.key 파일이 아니라 AWS Systems Manager Parameter Store(SecureString)에서 읽습니다. 이 페이지·백엔드 모듈은 기존 키 파일 트랙과 완전히 분리된 별도 구현이며, 기존 트랙은 이 모듈과 무관하게 그대로 동작합니다.

테스트 주의사항
  • 모두 조회 전용입니다. 주문·정정·취소 API는 호출하지 않습니다.
  • KIS Testbed는 토큰 발급이 1분당 1회로 제한되어 있어 연속 요청하지 마세요.
  • 모의 환경의 가격·거래량·체결시각은 실전 시세와 다를 수 있습니다.
AWS 사전 준비
  • /stock-coin-trade/kis/app_key, .../kis/secret, .../kis/account
  • /stock-coin-trade/kb/app_key, .../kb/secret
  • 파라미터 미생성 시 화면에 "SSM Parameter Store에 …이(가) 없습니다" 오류가 표시됩니다. 자세한 절차는 README의 "AWS SSM Parameter Store 연동 트랙" 참고.
