DOCKER CLASS · OHLCV DB

종목·연도별로 계속 갱신되는 일봉 OHLCV 데이터 서비스

별도 PostgreSQL(pg-stock)에 KOSPI·KOSDAQ 일봉을 최초 적재한 뒤 매일 한 번 증분 갱신합니다. 대시보드는 일일 배치가 만든 별도 집계 테이블을 조회하고, 원본 데이터는 내부 검색 화면과 API Key 기반 /openapi/v1/ohlcv/*에서 제공합니다. 퀀트 연구용 PostgreSQL(quant.html)과는 별개의 인스턴스입니다.

종목 선정 → 연도별 수집 → PostgreSQL upsert → CORS Open API 제공 흐름입니다.

1

수집 대상 선정

OHLCV_SYNC_TICKERS로 주요 종목, 쉼표 구분 종목 목록 또는 전체 종목을 선택합니다. 기본값은 주요 KOSPI·KOSDAQ 24종목입니다.

major · 005930,000660 · all
2

종목 × 연도 수집

최초 적재 후 매일 18:20에 최근 7일 보정 구간과 현재 연도를 한 번만 증분 갱신합니다. 같은 날짜의 중복 배치는 실행 이력 PK로 차단합니다.

APScheduler · 일 1회 · Asia/Seoul
3

검증 · Upsert

원본 upsert가 끝나면 전체·연도·시장 집계를 별도 스냅샷 테이블에 저장합니다. 화면 조회 시 원본 일봉을 다시 집계하지 않습니다.

summary_snapshot · yearly_summary · market_summary
4

내부 화면 · Open API

AG Grid 검색과 /openapi/v1/ohlcv/<ticker>?year=YYYY가 같은 DB를 조회합니다. Bearer API Key와 분당 제한을 적용하고 외부 브라우저용 CORS 헤더를 기본 제공합니다.

Access-Control-Allow-Origin: *
01

테이블 구조 — 종목마다 테이블을 만들지 않는 이유

종목별로 테이블을 따로 만들면 수천 개 종목을 감당하기 어려워, 종목 마스터 1개 + 공용 시세 1개로 구성합니다.

tickers (종목 마스터)

ticker_code
종목 코드. PK. 예: 005930
name / market
종목명과 시장 구분(KOSPI 등). 적재 배치는 현재 코드만 채우고 나머지는 비워 둡니다.
created_at
처음 발견되어 등록된 시각.

ohlcv (전 종목 공용 시세)

ticker_code, trade_date
복합 PK. 한 종목의 하루치 캔들 1행.
open / high / low / close
시가·고가·저가·종가.
adj_close / volume
수정종가와 거래량.

인덱스 · 적재 방식

idx_ohlcv_trade_date
날짜 범위 조회 최적화용 보조 인덱스.
적재 스크립트
execute_values + ON CONFLICT (ticker_code, trade_date) DO NOTHING으로 idempotent하게 삽입.
ohlcv 예시 행 (003080, 2025-01-02) 003080 | 2025-01-02 | 2,490.0 | 2,495.0 | 2,470.0 | 2,490.0 | 2,315.59 | 7,549

CSV 원본 컬럼(Date, Open, High, Low, Close, Adj Close, Volume)은 yfinance 응답 그대로이며, 적재 스크립트가 trade_date/open/high/low/close/adj_close/volume으로 이름을 바꿔 넣습니다.

02

접속 · 운영 정보

이 DB는 docker-class 저장소를 클론한 로컬/사내 환경에서만 뜨는 컨테이너입니다.

실행 위치

docker-class/postgresql/docker-compose.yml → 컨테이너명 pg-stock, 이미지 postgres:latest. DB 포트는 호스트에 공개하지 않고 postgresql_default Docker 네트워크로 백엔드와 직접 연결합니다.

접속 계정

DB명 admin. 계정·비밀번호는 저장소에 커밋하지 않고 docker-class/postgresql/.env.example을 복사한 .env로 관리합니다. 운영자는 해당 README의 "접속 정보" 절을 참고하세요.

데이터 범위

주요 KOSPI·KOSDAQ 종목은 2020-01-01부터 현재까지 우선 수집하고, 기존 전 종목 배치는 연도별 CSV 파이프라인으로 보완합니다. 상장 전 기간은 공급자가 빈 결과로 반환하며 거래정지·상장폐지 종목은 별도 검증이 필요합니다.
