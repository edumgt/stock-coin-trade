앱·서버 실습 환경 설치

M-able과 PC 로그인 환경을 준비한 뒤 이 저장소의 Docker 서비스를 기동합니다. KB 공식 샘플은 운영 모드이며 이 웹앱도 운영 조회 API만 사용합니다.

설치 범위

1
M-able 설치

계좌 개설·ID 등록과 신청 상태 확인에 사용합니다. 이 웹앱이 앱 로그인을 대행하지 않습니다.

2
Docker·Compose 준비

저장소 루트에서 컨테이너를 빌드합니다. kb.key는 이미지가 아니라 런타임에 읽기 전용으로 마운트됩니다.

3
서비스 기동
chmod 600 kb.key
docker compose up -d --build python-backend frontend
docker compose ps
KB는 모의투자 서버가 아니라 운영 API입니다. 이 과정은 토큰·시세·종목정보·호가·차트 조회만 제공하며 주문·정정·취소 코드는 포함하지 않습니다.
