KB 계좌 및 API 신청

역할: KB증권 계좌와 Open API 사용 권한을 준비합니다.

가입 순서

1
KB M-able 설치·비대면 계좌 개설

본인 명의 휴대폰과 신분증으로 계좌를 개설합니다. 이미 계좌가 있다면 신청 가능 계좌인지 포털에서 확인합니다.

2
KB증권 ID 등록·PC 로그인 수단 준비

앱에서 ID를 등록하고 필요하면 클라우드 인증서를 발급합니다. 비밀번호와 인증정보는 웹앱에 입력하지 않습니다.

3
Open API 신청/조회

KB증권 Open API 포털에서 신청 가능 계좌를 조회하고 API 그룹, 이용기간, 약관을 확인해 신청합니다.

리드타임: 계좌·ID·인증서 등록은 수 시간이 걸릴 수 있으므로 테스트 당일보다 먼저 완료하세요. 일부 계좌는 신청이 제한될 수 있습니다.
