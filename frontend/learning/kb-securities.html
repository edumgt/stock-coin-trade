국내·해외 선물옵션

KB증권은 M-able·H-able의 국내선물옵션 모의투자를 안내합니다. 단순 체험과 이수용 참가부문을 구분해 신청합니다.

국내·해외 주식

주식 모의투자 제공 방식은 상시 서비스 또는 이벤트·리그 등으로 달라질 수 있습니다. 앱의 현재 메뉴와 공지를 먼저 확인하세요.

파생상품 이수

실거래 등록을 위한 사전교육·모의거래 요건은 투자자 유형과 상품에 따라 달라집니다. 필요한 시간을 KB증권 화면에서 조회하세요.

이 페이지는 KB증권의 상품 가입·주문을 대행하지 않습니다. 실제 계좌 개설, 참가 가능 여부, 가상 투자금, 이수 기준과 메뉴명은 변경될 수 있으므로 신청 직전에 공식 화면을 확인하세요.

PART 1 · 신청 흐름

가입부터 모의투자 모드 접속까지

1

KB M-able 설치와 비대면 계좌개설

본인 명의 휴대폰과 신분증을 준비해 KB M-able을 설치하고 계좌개설 절차를 진행합니다. 계좌개설·이용 가능 조건은 앱의 최신 안내를 따릅니다.

2

앱에서 KB증권 ID 등록

계좌 개설 후 앱에서 ID·비밀번호 등록 및 로그인 상태를 확인합니다. 비밀번호와 인증 정보는 본인만 보관하고, 화면 캡처·메신저·공용 PC에 저장하지 않습니다.

3

PC용 KB증권 웹사이트에서 로그인

PC에서 KB증권 공식 웹사이트에 접속해 등록한 ID로 로그인합니다. 공동·클라우드·브라우저 인증서 등 필요한 로그인 수단을 확인하고, 공용 PC에서는 ID 저장과 자동 로그인을 사용하지 않습니다.

4

Open API 신청/조회 메뉴 열기

PC 웹사이트 로그인 후 상단 또는 고객서비스의 Open API 메뉴에서 Open API 신청/조회로 이동합니다. 본인 계좌를 선택하고 비밀번호를 직접 입력한 뒤 조회하여, 해당 계좌의 신청 가능 여부와 이용 조건을 확인합니다.

5

모의투자 참가부문을 선택해 신청

M-able의 국내선물옵션 모의투자 메뉴에서 단순 체험은 상시 모의투자, 수료증이 필요한 경우는 이수용 모의투자를 선택합니다. 앱에서 참가신청·취소와 모의투자 ID를 확인합니다.

6

모의투자 전용 ID로 다시 로그인

H-able은 모의투자 체크 후 모의투자 ID·비밀번호로 로그인하는 방식이 안내되어 있습니다. M-able은 국내선옵 모의투자 메뉴에서 진입합니다. 실제 계좌 화면이 아닌지 다시 확인합니다.

클라우드 인증서 로그인

인증서 등록을 마친 뒤 PC에서 본인 인증으로 로그인합니다

PC 로그인 창에서 클라우드인증서 로그인 탭을 선택하고 로그인 버튼을 누릅니다. 처음 사용하는 경우에는 화면의 인증서 등록 안내에서 본인의 공동인증서 보유 여부 또는 타사 클라우드 인증서 보유 여부에 맞는 절차를 선택하세요. 인증 과정에서 요구하는 본인 확인은 본인이 직접 진행합니다.

보안 설정: 주문시 자동서명은 본인 소유의 신뢰할 수 있는 기기에서만 필요성을 검토해 사용합니다. 공용 PC·공유 기기에서는 자동서명, ID 저장, 자동 로그인 기능을 사용하지 말고 반드시 로그아웃한 뒤 브라우저를 종료하세요.
OPEN API 신청/조회

로그인 후 본인 계좌의 Open API 신청 가능 여부를 확인합니다

PC 웹사이트에서 로그인한 뒤 Open API → Open API 신청/조회 메뉴로 이동합니다. 신청할 본인 계좌를 선택하고 비밀번호를 직접 입력한 뒤 조회를 선택합니다. 조회 화면의 신청 제한, 계좌 유형, 상품별 약정·등록 요건을 확인한 후에만 다음 신청 절차를 진행하세요.

신청 화면: 조회 후 신청 화면이 열리면 신청 계좌, 사용할 API 그룹, 이용기간을 먼저 대조합니다. 이어서 Open API 서비스 이용 약관과 개인정보 수집·이용 내용을 직접 읽고, 이해한 범위에서만 동의합니다. 계좌 또는 API 그룹이 의도한 내용과 다르면 신청을 중단하고 공식 안내를 확인하세요.

최종 신청 완료 후: 다시 Open API 신청/조회에서 신청현황을 열어 신청 계좌, 신청일자, 만료일, 갱신 가능 시점을 확인합니다. App Key와 App Secret이 발급된 경우에는 본인 서버의 환경변수 또는 비밀 관리 도구에만 저장합니다. 키는 모의·실전 환경과 계좌별로 다를 수 있으므로, 사용할 환경과 일치하는 값인지 확인하세요.

클라우드 인증서 가입·발급, ID 등록, 계좌 이용 등록은 본인 확인과 심사 상황에 따라 개인별로 수시간이 걸릴 수 있습니다.
모의투자나 PC 로그인 직전에 시작하지 말고, 충분한 시간을 두고 완료 여부를 확인하세요.

KB OPEN API PORTAL

개발 문서와 API 명세는 KB증권 Open API 포털에서 확인합니다

KB증권 Open API 포털은 서비스 사용신청, 개발가이드, API 문서, 공지·FAQ를 제공하는 공식 개발자 사이트입니다. 시세·종목·계좌·잔고 조회부터 주문·체결 연동, 투자 대시보드나 자동화 서비스 구현에 필요한 정보를 찾을 수 있습니다.

1 · 서비스 사용신청

KB증권 계좌를 준비한 뒤 포털 또는 KB증권 홈페이지에서 사용신청 가능 여부를 확인합니다. 신청이 완료되면 서비스 정보를 등록하고 App Key·App Secret을 발급받습니다.

2 · 개발가이드

App Key·App Secret으로 Access Token을 발급하고, HTTPS·JSON 요청과 Bearer Token 인증 흐름을 확인합니다. 토큰 만료와 호출 제한의 처리 방법도 먼저 읽습니다.

3 · API 문서

OAuth 인증, 국내주식, 해외주식 등 필요한 API를 검색해 요청·응답 명세와 오류 코드를 확인합니다. 전체 문서 다운로드와 언어별 샘플 생성 기능도 활용할 수 있습니다.

1

포털에서 서비스 사용신청과 키 발급 상태 확인

앞 단계에서 신청한 계좌와 환경에 맞는 App Key·App Secret인지 확인합니다. 키는 브라우저·Git·메신저에 저장하지 않고 서버 환경변수 또는 비밀 관리 도구에만 보관합니다.

2

개발가이드에서 인증·접속·오류 처리 확인

토큰을 발급한 뒤 만료 시에만 재발급하도록 구현합니다. 접속 URL, API 권한, 계좌 권한, 호출 제한은 서비스 환경과 API별로 다를 수 있으므로 실제 호출 전에 현재 문서를 대조합니다.

3

API 문서에서 조회 API부터 테스트

처음에는 시세·종목정보처럼 읽기 전용 API를 단일 호출로 검증합니다. 주문 API는 요청 필드, 한도, 상품 상태를 모두 확인하고 별도의 승인 절차와 손실 한도를 갖춘 뒤에만 다룹니다.

권장 순서: 계좌 개설 → Open API 사용신청 → App Key·App Secret 발급 및 안전한 보관 → Access Token 발급 → 읽기 전용 API 테스트 → 필요한 경우에만 주문 연동 순서로 진행하세요. 포털의 API 명세·접속 주소·제한 정책은 변경될 수 있으므로 코드에 고정하기 전에 최신 문서를 확인합니다.

PART 2 · 수동 테스트 시나리오

한 항목씩 확인하고 기록하기

아래 테스트는 실제 주문을 내지 않고도 화면과 흐름을 검증할 수 있도록 구성했습니다. 주문 단계는 반드시 모의투자 전용 화면이라는 표시와 가상 예탁금을 확인한 뒤, 최소 수량으로만 진행하세요.

테스트수동 조작기대 결과기록할 항목
T01 · 모드 확인모의투자 메뉴로 들어가 화면 상단의 모의투자 표시, 모의투자 ID, 가상 예탁금을 확인합니다.실거래 계좌가 아닌 모의투자 전용 모드임을 확인합니다.접속 일시 · 화면명 · 모의 ID 끝 2자리
T02 · 종목 검색관심 상품 1개를 검색하고 상품명·월물·거래소·현재가를 읽습니다.의도한 상품과 다른 종목을 선택하지 않았는지 확인합니다.검색어 · 선택 종목 · 현재가 시각
T03 · 주문 화면 점검매수/매도 화면을 열되 전송하지 않고, 수량·가격·주문구분·증거금 또는 가상 잔고 표시를 확인합니다.주문 조건을 입력하기 전 필요한 값과 위험 고지를 확인할 수 있습니다.주문 유형 · 최소 수량 · 취소 위치
T04 · 모의 주문 1건모의투자 표시와 가상 잔고를 다시 확인한 뒤 최소 수량으로 1건만 주문합니다. 체결 전에는 주문번호를 확인하고, 정정·취소 메뉴 위치도 찾습니다.주문 상태가 접수·체결·미체결 중 하나로 표시되고 이력에서 조회됩니다.주문 시각 · 상태 · 체결가 · 수수료 표시
T05 · 이력·손익 점검체결/미체결, 잔고, 실현·평가손익 화면을 각각 열어 같은 주문이 일치하는지 비교합니다.주문 1건이 잔고와 거래이력에 일관되게 반영됩니다.주문번호 · 잔고 변화 · 손익 표시
T04는 실제 거래 화면에서 실행하지 마세요. 화면의 모의투자 표시·가상 예탁금·모의 ID가 하나라도 확인되지 않으면 중단하고, 앱 고객지원 또는 공식 안내에서 현재 경로를 다시 확인하세요.
