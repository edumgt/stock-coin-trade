FRED · 경제지표 API 연동

미국 세인트루이스 연방준비은행의 경제 데이터로 금리·물가·고용을 조회합니다. 가입 → 키 발급 → 서버 설정 → 지표 조회 순서로 실습합니다.

1. 가입 및 API 키 발급

  1. FRED 공식 사이트의 My Account에서 계정을 만들고 로그인합니다.
  2. API Key 안내에서 API 키를 신청합니다. 발급된 32자리 키는 서버에 보관합니다.
  3. Python 환경에 requests를 설치합니다: pip install requests

2. 서버 환경변수 설정

# 서버의 .env (Git에 커밋하지 않음)
FRED_API_KEY=발급받은_키

이 사이트는 서버에 등록된 키로 연결합니다. 브라우저 입력이나 별도 키 등록 없이 다음 테스트 화면을 사용할 수 있습니다. 키를 변경한 뒤에는 백엔드 환경변수를 갱신하여 재기동합니다.

3. 요청과 응답 이해하기

항목사용법
지표 정보GET /fred/series · 이름, 단위, 주기, 최종 수정 시각
관측값GET /fred/series/observations · 날짜별 수치
공통 파라미터series_id=DGS10, api_key=서버 키, file_type=json
최근 데이터sort_order=desc, limit=30 (이 실습은 1~200개)

FRED 원본 주소는 https://api.stlouisfed.org입니다. 사이트에서는 /api/fred-test/series와 /api/fred-test/observations가 키를 붙여 대신 요청합니다.

Python 예제 · 서버에서 실행

import os
import requests

response = requests.get(
    "https://api.stlouisfed.org/fred/series/observations",
    params={
        "api_key": os.environ["FRED_API_KEY"],
        "file_type": "json",
        "series_id": "DGS10",
        "sort_order": "desc",
        "limit": 30,
    },
    timeout=15,
)
# 응답 URL에는 키가 포함되므로 URL이나 예외 원문을 출력하지 않습니다.
if response.status_code == 200:
    print(response.json()["observations"])
else:
    print("FRED 요청 실패:", response.status_code)

환경변수는 실행 전에 설정해야 합니다. Python 기본 기능만으로는 .env 파일을 자동으로 읽지 않습니다.

브라우저 예제 · 사이트의 서버 경유

const response = await fetch(
  '/api/fred-test/observations?series_id=DGS10&limit=30'
);
const data = await response.json();
if (data.ok) console.log(data.result.observations);

4. 대표 지표와 해석

코드내용주기·단위
DGS10 / DGS2미국 국채 10년 / 2년 금리일별 · %
FEDFUNDS실효 연방기금금리월별 · %
CPIAUCSL미국 소비자물가지수월별 · 지수 (전년 대비 상승률 아님)
UNRATE미국 실업률월별 · %
T10Y2Y국채 10년−2년 금리차일별 · %p
VIXCLSVIX 종가일별 · 지수
실시간 시세가 아닙니다. 조회 시각과 관측 기준일은 다르며 발표 지연·휴일·사후 수정이 있을 수 있습니다. 원본의 "."는 결측값이며 화면에서는 null로 표시합니다. 지표마다 단위와 발표 주기를 먼저 확인하세요.

5. 테스트 및 오류 확인

  1. 지표를 선택하고 ‘지표 정보’를 눌러 단위·주기를 확인합니다.
  2. ‘관측값 조회’로 최신 유효 수치, 기준일과 JSON을 확인합니다.
  3. DGS10과 DGS2를 각각 조회하거나 T10Y2Y로 금리차를 확인합니다.

설정 누락: 서버 FRED_API_KEY 확인 · 잘못된 지표/키: 코드와 인증 확인 · 호출 제한/연결 실패: 잠시 후 재시도. 동일 요청은 60초간 캐시되며 캐시의 원래 조회 시각을 유지합니다.
