DART · 전자공시 API 연동

금융감독원 OpenDART로 국내 상장사의 기업개황·공시목록·재무제표를 조회합니다. 가입 → 인증키 발급 → 서버 설정 → 조회 순서로 실습합니다.

1. 가입 및 인증키 발급

  1. OpenDART 공식 사이트에서 회원가입 후 로그인합니다.
  2. 상단 메뉴 인증키 신청/관리 → 인증키 신청에서 사용 목적을 적고 신청하면 이메일 인증 후 40자리 인증키가 발급됩니다.
  3. 인증키 관리에서 키 상태(정상)와 일일 요청 한도(기본 20,000건)를 확인합니다. 키는 서버에만 보관합니다.
  4. Python 환경에 requests를 설치합니다: pip install requests

2. 서버 환경변수 설정

# 서버의 .env (Git에 커밋하지 않음)
DART_API_KEY=발급받은_40자리_인증키

이 사이트는 서버에 등록된 키로 연결합니다. 브라우저 입력이나 별도 키 등록 없이 다음 테스트 화면을 사용할 수 있습니다. 키를 변경한 뒤에는 백엔드 환경변수를 갱신하여 재기동합니다.

3. 요청과 응답 이해하기

항목사용법
고유번호 목록GET /api/corpCode.xml · ZIP 안에 XML. 종목코드(6자리) → 고유번호(corp_code, 8자리) 매핑. 서버가 30일 캐시
기업개황GET /api/company.json · corp_code · 회사명·대표자·시장구분·설립일·결산월
공시목록GET /api/list.json · corp_code, bgn_de, end_de, page_count · 접수번호·보고서명·접수일
재무제표 주요계정GET /api/fnlttSinglAcnt.json · corp_code, bsns_year, reprt_code · 자산·부채·자본·매출·영업이익·당기순이익
공통 파라미터crtfc_key=서버 키. 모든 API 는 종목코드가 아니라 고유번호로 조회

DART 원본 주소는 https://opendart.fss.or.kr입니다. 사이트에서는 /api/dart-test/company·/disclosures·/financials가 종목코드를 고유번호로 바꾸고 키를 붙여 대신 요청합니다.

응답 status 코드

status의미
000정상
010 / 011미등록 키 / 사용할 수 없는 키
013조회된 자료 없음 (연도·보고서 구분 확인)
020일일 요청 한도 초과
800시스템 점검

HTTP 상태는 항상 200 이고 성공·실패는 본문 status로 구분합니다. 이 점이 다른 API와 가장 다른 부분입니다.

Python 예제 · 서버에서 실행

import os
import requests

response = requests.get(
    "https://opendart.fss.or.kr/api/company.json",
    params={"crtfc_key": os.environ["DART_API_KEY"], "corp_code": "00126380"},  # 삼성전자 고유번호
    timeout=15,
)
body = response.json()
# 응답 URL에는 키가 포함되므로 URL이나 예외 원문을 출력하지 않습니다.
if body.get("status") == "000":
    print(body["corp_name"], body["ceo_nm"], body["est_dt"])
else:
    print("DART 오류:", body.get("status"), body.get("message"))

브라우저 예제 · 사이트의 서버 경유

4. 보고서 구분과 해석

reprt_code보고서금액 기준
11011사업보고서연간 (당기 = 그 해 전체)
11012반기보고서손익은 반기 누적
110131분기보고서손익은 1분기
110143분기보고서손익은 3분기 누적
DART는 국내 상장사만 제공합니다. 우선주(005935 등)는 보통주 코드(005930)로 회사를 찾습니다. 연결(CFS)이 없는 회사는 별도(OFS) 재무제표를 보여 주며 fs_div로 구분합니다. 금액 단위는 원(KRW)이고 결손·손실은 음수입니다. 사업보고서는 보통 다음 해 3월 말에 제출되므로 올해 연도는 비어 있을 수 있습니다.

5. 테스트 및 오류 확인

  1. 종목코드를 입력하고 ‘기업개황’을 눌러 회사명·시장구분·결산월을 확인합니다.
  2. ‘공시목록’으로 최근 90일 공시와 DART 뷰어 링크를 확인합니다.
  3. ‘재무제표’로 사업연도·보고서 구분을 바꿔 가며 자산·부채·매출·영업이익 요약과 JSON을 확인합니다.

설정 누락: 서버 DART_API_KEY 확인 · status 010/011: 키 발급 상태 확인 · status 013: 연도·보고서 변경 · status 020: 내일 재시도. 동일 요청은 60초간 캐시되며 고유번호 목록은 30일간 캐시됩니다.
