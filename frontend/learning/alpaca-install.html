Alpaca Paper 실습 환경

역할: Paper API를 실행할 Docker와 선택적 SDK 환경을 준비합니다.

설치 순서

1
.env 권한 제한
chmod 600 .env
2
웹앱 빌드·기동
docker compose up -d --build python-backend frontend
docker compose ps
3
선택: 공식 Python SDK
python -m venv .venv
. .venv/bin/activate
pip install alpaca-py
웹앱 주문 테스트는 paper-api.alpaca.markets에 고정되어 있습니다. Live 도메인 전환 설정은 제공하지 않습니다.
