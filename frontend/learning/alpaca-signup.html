Alpaca Paper 계정 준비

역할: Alpaca 가입과 Paper Trading 계정 생성을 안내합니다.

가입 순서

1
이메일 계정 생성과 확인

Alpaca 공식 가입 화면에서 계정을 만들고 이메일 확인을 완료합니다. 비밀번호는 이 웹앱에 입력하지 않습니다.

2
Paper Trading 선택 또는 생성

대시보드의 계정 선택기에서 Paper Trading을 선택합니다. Live Trading 키를 만들지 않습니다.

3
Home의 API Keys 패널 확인

Paper 계정이 선택된 상태에서 API Keys 패널이 보이는지 확인합니다. 키 발급은 다음 단계에서 진행합니다.

환경 확인: 화면에 Paper Trading 표시가 있는지 먼저 확인하세요. Live 승인·입금·실거래 설정은 이 과정의 범위가 아닙니다.
