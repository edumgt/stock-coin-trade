table로 지표 대시보드 만들기

여러 지표값을 차트에서 따로 읽는 대신, table로 화면 한쪽에 요약 패널을 띄웁니다. 현재가·RSI·추세를 한눈에 보는 대시보드를 만들며 코스를 마무리합니다.

TradingView Pine 편집기 열기 ↗

지표 대시보드 코드

table.new()로 표 위치와 크기를 정하고, table.cell()로 칸마다 값을 채웁니다. 숫자는 str.tostring()으로 문자열로 바꿔 넣고, 조건에 따라 배경색을 다르게 줍니다.

//@version=6
indicator("지표 대시보드", overlay=true)
r = ta.rsi(close, 14)
// 표는 var로 한 번만 만들고, 마지막 봉에서만 값을 채운다.
var table t = table.new(position.top_left, 2, 2, border_width=1)
if barstate.islast
    table.cell(t, 0, 0, "RSI", text_color=color.white, bgcolor=color.gray)
    table.cell(t, 1, 0, str.tostring(r, "#.0"),
         bgcolor = r > 70 ? color.red : r < 30 ? color.green : color.gray,
         text_color=color.white)
    table.cell(t, 0, 1, "추세")
    table.cell(t, 1, 1, close > ta.sma(close, 20) ? "상승" : "하락")
표가 안 보이나요? 두 가지를 확인하세요. ① 표는 var로 한 번만 만들고 if barstate.islast 안에서 채워야 합니다. 매 봉마다 table.new를 부르면 표가 제대로 그려지지 않습니다. ② overlay=true여야 가격 차트 위에 표가 뜹니다. overlay=false면 빈 보조창이 생기고 표가 잘 안 보입니다. Pine 편집기는 화면 우측에 있으므로 표를 position.top_left(좌측 상단)에 두어 가려지지 않게 했습니다.

이번 단계의 새 명령어

table.new(pos, cols, rows)표를 만들고 화면 위치(예: position.top_right)와 칸 수를 정합니다.
table.cell(t, col, row, text)지정한 칸에 텍스트를 넣습니다. text_color, bgcolor로 색을 줍니다.
str.tostring(num, fmt)숫자를 문자열로 바꿉니다. "#.0"은 소수 첫째 자리까지 표시합니다.
position.*표 위치 상수. top_right, bottom_left 등 화면 구석을 지정합니다.
이 단계의 라이브 미리보기는 TradingView Pine 편집기에서 확인합니다. 위 코드를 복사해 붙여넣고 차트에 추가를 누르면 좌측 상단에 대시보드가 나타납니다.
