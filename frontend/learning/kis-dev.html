접근 토큰

절대 금지: App Secret, 접근 토큰, 계좌번호 전체를 이 웹사이트의 입력창·브라우저 저장소·프론트엔드 JavaScript에 넣거나 Git에 커밋하지 마세요. 이 사이트의 기존 Open API 키와 KIS API 키는 서로 다른 키입니다.
STEP 1 · KIS Developers API 신청

Testbed용 계좌·키를 따로 발급받습니다

KIS Developers는 서비스 신청 후 상품에 맞는 API 문서, 종목 정보 파일, Testbed와 GitHub REST·WebSocket 샘플을 제공합니다. 이 웹앱에서 필요한 것은 국내주식 모의투자(Testbed) 범위입니다.

1

1단계의 모의투자 계좌 준비 확인

1단계 · 가입에서 모의투자 참가 신청을 마치고 모의 계좌번호를 확인했는지 다시 확인합니다. API 신청은 이 모의 계좌를 기준으로 진행하며 실전 계좌번호를 복사하지 않습니다.

2

KIS Developers에서 API 신청

로그인 후 상단의 API 신청으로 이동해 모의투자 계좌와 사용할 서비스를 선택합니다. 화면에 표시되는 약관·이용 조건·신청 가능 여부를 확인하고 완료합니다.

3

신청현황에서 모의 App Key·App Secret 확인

발급된 값은 한 번만 안전한 비밀 저장소에 보관합니다. 이 웹앱에는 모의 키만 사용하며, 계좌번호는 잔고 조회를 사용할 때만 필요합니다.

이 화면에서 필요한 정보: ① 구분이 모의투자계좌인지, ② 계좌번호가 CANO-상품코드 형태인지, ③ 모의투자 행에 연결된 App Key와 App Secret이 발급됐는지, ④ 신청일자·만료일을 통해 서비스가 유효한지를 확인합니다. 실전투자계좌 행의 값은 이 웹앱에 사용하지 않습니다.

STEP 3 · .env 만들기

키는 서버의 .env로 전달합니다

1

모의 키 두 값을 정확히 기록

App-KEY와 Secret은 KIS가 발급한 그대로 사용합니다. 공백·따옴표·키 이름 오타가 있으면 인증에 실패합니다.

2

프로젝트 루트에 .env 생성

Docker Compose가 이 파일의 값을 컨테이너 환경변수로 전달합니다. .env는 Git 제외 대상입니다.

3

잔고 조회를 할 경우에만 모의계좌 추가

계좌번호는 12345678-01처럼 CANO와 상품코드를 하이픈으로 연결합니다. 현재가·차트·호가·지수 조회에는 필요하지 않습니다.

# 프로젝트 루트의 .env (절대 커밋하지 않음)
KIS_PAPER_APP_KEY=모의투자_App_Key
KIS_PAPER_APP_SECRET=모의투자_App_Secret
KIS_PAPER_ACCOUNT_NO=12345678-01
단일 설정 방식: .env의 KIS_PAPER_APP_KEY, KIS_PAPER_APP_SECRET, KIS_PAPER_ACCOUNT_NO(12345678-01 형식)를 채웁니다. 별도 키 파일 fallback은 없으며, 값이 바뀌면 백엔드 컨테이너를 재생성합니다.
주의: 키·Secret·접근 토큰·계좌번호는 이 페이지나 테스트 화면의 입력창에 넣지 않습니다. 서버 파일 또는 배포 Secret에만 둡니다. 외부에 공개된 환경이라면 잔고 조회 경로에 별도의 접근 통제도 필요합니다.
STEP 4 · .env 상세

파일 형식·읽는 위치·사용 범위를 정확히 맞춥니다

이 웹앱은 저장소 루트 .env에 설정한 값을 사용합니다. 인증 키만 있다면 시세·차트·호가·지수는 가능하지만, 잔고 조회와 주문성 API에는 KIS_PAPER_ACCOUNT_NO도 필요합니다.

항목필수 여부형식 및 용도
app_key필수KIS Developers에서 발급한 모의투자 App Key입니다. App-KEY 표기도 읽을 수 있으나, 이 파일에서는 소문자 app_key를 권장합니다.
secret필수위 App Key에 대응하는 모의투자 App Secret입니다. 공백·따옴표·인라인 주석을 붙이지 않습니다.
account잔고 조회 시 필수CANO-상품코드 형식입니다. 예: 12345678-01. 하이픈 앞은 8자리 계좌번호, 뒤는 계좌상품코드입니다.
# 올바른 예시: 한 줄에 한 값만 둡니다.
KIS_PAPER_APP_KEY=발급받은_모의_App_Key
KIS_PAPER_APP_SECRET=발급받은_모의_App_Secret
KIS_PAPER_ACCOUNT_NO=12345678-01

# 잘못된 예시: 이 파서는 '#' 뒤쪽도 값으로 읽습니다.
KIS_PAPER_ACCOUNT_NO=12345678-01 # 모의 계좌
1

파일 권한과 Git 제외 확인

.env는 프로젝트 루트에 두고 chmod 600 .env를 적용하며 Git에 추가하지 않습니다.

2

필수 변수 확인

백엔드는 KIS_PAPER_APP_KEY와 KIS_PAPER_APP_SECRET을 함께 요구합니다. 잔고·주문에는 KIS_PAPER_ACCOUNT_NO도 필요합니다.

3

Docker 재생성 후 확인

.env를 새로 만들거나 변경했다면 docker compose up -d --build --no-deps python-backend로 백엔드를 재생성한 뒤 조회합니다.

실전 키 금지: 이 파일에는 실전 App Key·Secret 또는 실전 계좌번호를 넣지 마세요. 현재 이 웹앱 KIS 모듈은 openapivts Testbed 조회에만 사용합니다.
STEP 5 · Git 제외 확인

비밀값 파일이 저장소에 잡히지 않는지 확인합니다

이 프로젝트의 .gitignore에는 .env와 .env.* 제외 규칙이 설정되어 있습니다. 공유용 예시는 가짜 값만 담은 .env.example을 사용하세요.

# .gitignore — 실제 비밀값 파일은 Git에서 제외
.env
.env.*
!.env.example
*.key

# 확인: 출력이 비어야 정상
git ls-files | grep -E '\.key$|\.pem$|\.env$'
공유 금지: App Key·App Secret·접근 토큰·계좌번호가 포함된 .env, 캡처 이미지, 로그를 Git·메신저·이메일·브라우저 코드에 올리지 마세요. 이미 노출됐다면 KIS Developers에서 해당 키를 폐기하거나 재발급하고, 노출된 저장소 이력도 즉시 점검하세요.

선택 A · MCP의 역할과 경계

MCP는 개발 보조 도구이며, 공개 웹앱의 주문 백엔드가 아닙니다

공식 MCP 안내는 API 문서·샘플을 자연어로 찾는 Code Assistant MCP와, 시세·계좌·주문·정정·취소 API를 호출할 수 있는 Trading MCP를 설명합니다. 특히 Trading MCP는 실제 요청을 만들 수 있으므로 개발자의 제한된 로컬 도구로만 사용합니다.

문서 탐색 MCP

“국내주식 모의 현재가 API”, “주문 정정 필수값”처럼 문서·샘플을 찾고 이해하는 데 사용합니다. 찾은 결과는 항상 공식 명세로 재확인합니다.

거래 MCP

계좌·시세·주문성 API를 실행할 수 있습니다. 테스트용 모의 키만, 개발자가 직접 확인하는 세션에서 사용합니다.

웹앱 서버

사용자 요청을 검증한 자체 백엔드만 KIS REST API를 호출합니다. MCP 프로세스를 브라우저 요청의 프록시로 노출하지 않습니다.

금지할 연결: 브라우저의 자연어 입력을 Trading MCP에 그대로 전달하거나, MCP 설정 파일·App Secret을 프론트엔드에 넣거나, 인터넷에 공개된 MCP 서버로 주문 권한을 제공하지 않습니다. MCP와 웹앱은 별도 프로세스·별도 권한·별도 로그로 분리합니다.

선택 B · MCP · VS Code / Codex

MCP로 자연어로 KIS API 사용하기

이 저장소에는 한국투자증권의 공식 Code Assistant MCP와 Trading MCP 연결 설정이 포함되어 있습니다. 코드 검색용은 API와 샘플을 찾고, 거래용은 모의투자 시세·잔고·주문 API를 호출합니다. 웹앱 서버와는 별도 프로세스로 실행됩니다.

1

공식 서버 설치

저장소 루트에서 설치 스크립트를 실행합니다. 공식 소스와 의존성은 Git에서 제외된 mcp/에 저장됩니다. Python 3.12+와 Git이 필요합니다.

2

모의투자 키 확인

루트 .env의 KIS_PAPER_* 값을 재사용합니다. 계좌번호는 12345678-01 형식입니다.

3

VS Code 보조 사이드바에서 연결

Codex 패널은 .codex/config.toml의 KIS MCP 설정을 사용합니다. Ctrl+Shift+P에서 Codex: Open Codex Sidebar를 실행해 패널을 엽니다. Copilot Chat을 쓰는 경우에는 .vscode/mcp.json을 사용합니다.

4

도구 호출 확인

거래 MCP는 모의 주문 도구도 제공하므로 요청 내용과 계좌를 확인한 뒤 실행합니다.

bash scripts/setup_kis_mcp.sh
python3 scripts/kis_mcp.py code --check
python3 scripts/kis_mcp.py trade --check

VS Code 오른쪽 Codex 패널에서 KIS Code Assistant MCP로 국내주식 현재가 API 찾아줘처럼 질문하세요. 패널이 보이지 않으면 Ctrl+Shift+P → Codex: Open Codex Sidebar를 실행합니다. 자세한 내용은 저장소 README.md의 “VS Code 보조 사이드바에서 KIS MCP 사용” 절을 참고하세요.

거래 실행기는 실전 키를 공식 서버에 전달하지 않습니다. 공식 서버의 ENV=live는 .env.live 전송 설정 파일 이름이며, 거래용 자격 증명은 KIS_PAPER_*입니다.
