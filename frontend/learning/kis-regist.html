KIS 모의투자 실습 · 1단계 가입

한국투자증권 가입과 모의투자 계좌 준비

KIS Open API를 쓰려면 먼저 한국투자증권 고객 ID와 모의투자 전용 계좌가 있어야 합니다. 이 단계에서는 계좌 개설, 모의투자 참가 신청, 모의 계좌번호(CANO-상품코드) 확인까지만 진행합니다. API 키는 아직 발급하지 않습니다.

STEP 0 · 시작 전 구분

이 웹앱 회원가입과 한국투자증권 가입은 서로 다릅니다

이 웹앱 계정

이 사이트의 모의 주식·코인 서비스에 로그인하는 계정입니다. KIS App Key를 만들거나 증권 계좌를 개설하지 않습니다.

한국투자증권 고객 ID·계좌

한국투자증권의 계좌 및 온라인 서비스용입니다. KIS Developers의 API 신청은 이 쪽의 본인 인증·계좌와 연결됩니다.

KIS Developers

API 문서·Testbed·오류코드·샘플을 확인하고 Open API 서비스를 신청하는 공식 개발자센터입니다.

아래 순서는 현재 KIS Developers와 한국투자증권 웹 안내를 바탕으로 한 학습용 체크리스트입니다. 실제 신청 화면의 약관, 가능한 계좌·상품, 인증 방식은 신청 시점의 공식 화면을 우선합니다.
STEP 1 · 한국투자증권 가입과 계좌 준비

먼저 증권사 고객 ID와 목적에 맞는 계좌를 준비합니다

1

한국투자증권 계정 만들기 또는 로그인

KIS Developers의 API 신청 버튼은 한국투자증권 로그인 화면으로 이동합니다. 이미 계좌가 있다면 고객 ID 상태와 연결된 계좌를 확인합니다. 이 웹앱의 회원가입 정보나 비밀번호를 입력하는 곳이 아닙니다.

2

계좌가 없다면 비대면 계좌개설 진행

한국투자증권 안내상 모바일 계좌개설에는 본인 신분증, 본인 명의 휴대폰, 보유 은행·증권사 계좌가 필요합니다. 계좌 개설 뒤 온라인 이용을 위해 고객 ID 등록·계좌 연결이 필요한 경우도 있습니다.

3

모의와 실전을 여기서 갈라서 결정

이 웹앱 모듈은 모의 Testbed 조회 전용이므로 처음에는 모의투자 신청과 모의 API 키만 사용합니다. 실전 계좌·실전 키는 이 모듈 설정에 넣지 않습니다.

한국투자증권 로그인·가입 ↗ KIS Developers 열기 ↗
입력 위치를 구분하세요: 주민등록증, 휴대폰 인증, 계좌 비밀번호, 인증서 정보는 한국투자증권 공식 앱·웹사이트에서만 입력합니다. 이 웹앱과 KIS Developers 문서 페이지에는 입력하지 않습니다.
STEP 1-1 · 한국투자 앱

한국투자 앱을 설치하고 앱으로 로그인합니다

한국투자증권의 모바일 앱(한국투자)은 비대면 계좌개설, 고객 ID 등록, 인증서 발급·관리, 모의투자 참가 신청에 쓰입니다. PC 홈페이지의 스마트폰 인증 로그인도 이 앱의 QR코드 스캔으로 승인하므로, 1단계에서는 앱 로그인이 먼저 되어야 합니다.

1

앱 설치와 첫 로그인

앱스토어(iOS) 또는 Play 스토어(Android)에서 한국투자증권 공식 앱을 설치합니다. 계좌가 없으면 앱의 비대면 계좌개설(본인 신분증, 본인 명의 휴대폰, 타행 계좌 필요)을 진행하고, 이미 계좌가 있으면 고객 ID 또는 계좌번호로 본인 인증 후 앱에 로그인합니다.

2

앱 로그인 수단 등록

처음 로그인한 뒤 간편비밀번호(6자리), 생체인증(지문·얼굴), 인증서 중 자주 쓸 수단을 등록해 둡니다. 이후 앱 실행 시 이 수단으로 바로 로그인합니다. 인증서는 앱의 인증/보안센터에서 발급·관리하며, PC 인증서 로그인에도 같은 인증서를 씁니다.

3

PC 홈페이지 로그인은 앱 QR 스캔으로 승인

PC 로그인 화면에서 스마트폰 인증 탭을 열면 QR코드가 표시됩니다. 앱에서 전체메뉴 → QR코드 스캔을 열어 PC 화면의 QR을 비추고 인증 유효시간 안에 승인하면 PC가 로그인됩니다. 인증서 로그인을 쓸 때는 앱에서 발급한 클라우드 인증서로 PC에서 로그인합니다.

4

앱에서 모의투자 참가 신청도 가능

앱의 전체메뉴에서 모의투자 메뉴로 들어가 참가 신청과 모의 계좌 확인을 할 수 있습니다. PC 모의투자 안내 화면과 같은 고객 ID 기준이므로 어느 쪽에서 신청해도 결과는 같습니다. 다음 STEP 2 는 PC 화면 기준으로 설명합니다.

STEP 2 · 모의투자 계좌 받기

KIS Testbed용 모의계좌를 신청하고 번호를 확인합니다

이 웹앱에서 사용하는 KIS 계좌는 실전 계좌가 아니라 한국투자증권의 주식/선물옵션 모의투자에서 발급받는 모의투자 전용 계좌입니다. 모의투자는 투자 체험과 학습을 위한 서비스이며, 신청 가능한 리그·기간·대상 상품은 그때그때 공식 화면의 안내를 따릅니다.

1

공식 모의투자 안내로 이동하고 로그인

아래의 공식 안내에서 모의투자안내 또는 참가 신청 화면으로 이동합니다. 한국투자증권 고객 ID로 로그인하며, 이 웹앱 계정으로는 신청할 수 없습니다.

2

참가 신청 정보를 선택

신청 화면에서 모의투자 비밀번호, 참여 리그 또는 투자 기간, 개인정보·약관 동의 등 현재 표시되는 항목을 확인하고 제출합니다. 항목명과 참가 조건은 바뀔 수 있으므로 화면의 최신 안내를 우선합니다.

3

신청 완료 후 모의계좌 정보 확인

모의투자 서비스의 나의계좌 → 계좌정보에서 새로 생성된 모의투자 계좌번호를 확인합니다. 계좌번호 전체를 메신저·캡처·Git에 공유하지 않습니다.

4

계좌번호를 kis.key 형식으로 분리

화면의 계좌번호가 12345678-01처럼 보이면 앞 8자리(CANO)와 뒤 2자리(상품코드)를 하이픈으로 유지해 account=12345678-01로 적습니다. 이 값은 잔고 조회와 향후 주문성 API에 필요합니다.

5

모의계좌와 모의 API 키를 같은 환경으로 맞춤

다음 단계(2단계 · 키 발급)에서 KIS Developers API 신청 시 모의투자 계좌에 대응하는 키를 발급받습니다. 실전 계좌·실전 키와 한 파일에 섞지 않습니다.

확인 항목이 웹앱에 쓰는 방법주의
모의투자 계좌번호account=CANO-상품코드로 kis.key에 저장현재가·차트·호가·지수 조회에는 필요 없고, 잔고 조회부터 필요합니다.
모의투자 비밀번호한국투자증권 모의투자 서비스에서만 사용kis.key, 이 웹앱, KIS API 요청에 넣지 않습니다.
실전 증권계좌이 모듈에서는 사용하지 않음실전 계좌번호·실전 키를 Testbed 파일에 기록하지 않습니다.
공식 모의투자 안내 열기 ↗
계좌가 바로 보이지 않을 때: 신청 완료 상태, 선택한 투자 기간, 현재 로그인한 고객 ID를 다시 확인하세요. 모의투자 서비스의 계좌 정보가 확인되기 전에는 account를 추측해 넣지 말고, KIS Developers의 모의 API 신청도 실제 표시된 모의계좌를 기준으로 진행합니다.
STEP 3 · 계좌번호 읽는 법

CANO와 계좌상품코드를 구분합니다

모의투자 계좌번호는 12345678-01처럼 표시됩니다. KIS API는 이 값을 두 필드로 나눠 받으며, 이 웹앱은 account=CANO-상품코드 한 줄로 적으면 서버가 하이픈 기준으로 분리합니다.

위치KIS 필드명의미자릿수
하이픈 앞CANO종합계좌번호 (고객 계좌 식별)8자리
하이픈 뒤ACNT_PRDT_CD계좌상품코드 (계좌 종류)2자리
상품코드는 임의로 바꾸지 않습니다. 01은 종합/위탁, 03은 선물옵션, 22는 연금처럼 증권사가 계좌 개설 시 부여한 값입니다. "01이 안 되니 02로 바꿔 보자" 식으로 수정하면 KIS 서버가 계좌를 찾지 못해 잔고 조회와 주문이 모두 실패합니다.
STEP 4 · 모의와 실전의 차이

모의투자와 실전투자는 계좌와 API 키가 서로 다릅니다

모의투자는 한국투자증권 회원으로 로그인한 뒤 모의투자 참가를 신청하고, 발급된 모의투자용 계좌번호와 다음 단계의 모의 App Key·Secret을 사용합니다. 실제 자금 주문을 하려면 주식 거래가 가능한 별도의 실전 계좌, 실전 서비스 신청, 실전 App Key·Secret이 필요하지만 이 실전연습에서는 사용하지 않습니다.

학습 환경의 원칙: 이 실전연습에서는 모의투자 계좌와 모의 API 키만 사용합니다. 실전 계좌번호·실전 App Key·Secret·TTTC 거래 ID를 kis.key, .env 또는 코드에 넣지 마세요. 모의투자 신청에는 실전 거래용 계좌가 항상 필요한 것은 아니며, 가입·이용 조건은 공식 모의투자 안내를 따릅니다.
