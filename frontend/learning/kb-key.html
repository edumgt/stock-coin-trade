App Key · App Secret 발급

신청현황의 같은 행에서 발급된 Key와 Secret 한 쌍을 확인합니다. 이 값은 브라우저나 소스코드에 입력하지 않고 서버 비밀값으로만 보관합니다.

같은 신청 행

API 그룹 확인

현재가·종목정보·호가·차트 TR이 신청 권한에 포함됐는지 확인합니다.

외부 노출 금지

캡처·메신저·Git·브라우저 저장소에 원문을 남기지 않습니다.

서버 파일 형식

# 저장소 루트 kb.key
AppKey=발급받은_App_Key
Secret=같은_행의_App_Secret
파서는 AppKey/app_key와 Secret/AppSecret/app_secret을 허용하지만, 교육 과정에서는 위 두 이름으로 통일합니다. 예비 kb2.key는 앱이 읽지 않습니다.
