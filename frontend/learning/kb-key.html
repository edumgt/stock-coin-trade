KB API 인증키 발급

역할: App Key와 App Secret을 발급받아 안전하게 보관합니다.

발급·보관 체크리스트

같은 신청 행

서로 다른 신청 건의 App Key와 Secret을 섞지 않습니다.

API 그룹 확인

현재가·종목정보·호가·차트 TR이 신청 권한에 포함됐는지 확인합니다.

외부 노출 금지

캡처·메신저·Git·브라우저 저장소에 원문을 남기지 않습니다.

.env 형식

# 저장소 루트 .env
KB_APP_KEY=발급받은_App_Key
KB_APP_SECRET=같은_행의_App_Secret
백엔드는 위 두 환경변수 이름만 사용합니다. 보존용 KB_SECONDARY_APP_KEY·KB_SECONDARY_APP_SECRET은 앱이 읽지 않습니다.
