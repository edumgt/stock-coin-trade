Alpaca Paper 환경 설정

역할: .env 자격 증명과 Paper 전용 연결 상태를 확인합니다.

서버 설정 상태

○ Key·Secret
○ .env 설정
○ 환경변수 전달
○ Paper 고정
로그인 후 서버 설정 상태를 확인합니다.

단일 설정 방식

루트 .env

ALPACA_API_KEY와 ALPACA_SECRET_KEY를 함께 설정합니다.

Docker Compose

Compose가 .env 값을 컨테이너 환경변수로 전달합니다.

안전 경계

Trading API는 Paper, Market Data는 읽기 전용 도메인으로 고정됩니다.
