Korbit Open API: 공개 데이터와 권한 분리

이 웹앱은 API Key 없이 사용할 수 있는 Korbit 공개 시세·호가 API부터 확인합니다. 개인 자산·주문·입출금 API는 생성한 키의 권한과 서명이 필요하므로 공개 화면에 연결하지 않습니다.

1 · 공개 API

KRW 거래쌍의 시세·호가를 먼저 조회합니다

현재가

GET /v2/tickers?symbol=btc_krw

호가

GET /v2/orderbook?symbol=btc_krw

최근 체결·캔들

/v2/trades, /v2/candles는 공식 명세의 필수값을 확인해 추가합니다.

curl 'https://api.korbit.co.kr/v2/tickers?symbol=btc_krw'
curl 'https://api.korbit.co.kr/v2/orderbook?symbol=btc_krw'

2 · 개인 API 키

권한을 최소화하고 서명 요청은 서버에서만 만듭니다

Korbit 개인 API는 키별로 자산 조회, 주문 조회, 주문 신청, 입금·출금 조회·신청 권한을 따로 설정합니다. 초기에는 공개 API만 사용하고, 개인 조회가 필요할 때도 자산 조회 권한만 둡니다.

KORBIT_API_KEY=발급받은_키
KORBIT_API_SECRET=발급받은_비밀값
주의: 이 웹앱에는 Korbit 개인 잔고, 주문, 취소, 입출금 API가 구현되어 있지 않습니다. 특히 출금 권한은 자동화 기본값으로 사용하지 마세요.
