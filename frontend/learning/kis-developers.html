PART 2 · 계좌 준비

모의투자와 실전투자는 계좌와 API 키가 서로 다릅니다

모의투자는 한국투자증권 회원으로 로그인한 뒤 모의투자 참가를 신청하고, 발급된 모의투자용 ID·계좌번호와 모의 App Key·Secret을 사용합니다. 실제 자금 주문을 하려면 주식 거래가 가능한 별도의 실전 계좌, 실전 서비스 신청, 실전 App Key·Secret이 필요합니다.

신청 완료 후: 모의투자 안내의 나의계좌 → 계좌정보에서 새로 생성된 모의투자 전용 계좌번호를 확인합니다. 이 값만 KIS_ACCOUNT_NO에 설정하고, 주문 전에는 모의 계좌·KIS_MODE=mock·VTTC 거래 ID가 모두 선택됐는지 다시 확인하세요.

학습 환경의 원칙: 이 페이지에서는 모의투자 계좌와 모의 API 키만 사용합니다. 실전 계좌번호·실전 App Key·Secret·TTTC 거래 ID를 .env 또는 코드에 넣지 마세요. 모의투자 신청에는 실전 거래용 계좌가 항상 필요한 것은 아니며, 가입·이용 조건은 공식 모의투자 안내를 따릅니다.

PART 4 · 서버 환경 설정

값을 코드에서 분리해 안전하게 구성합니다

KIS Developers의 신청현황에서 본인 계좌 유형에 맞는 App Key와 App Secret을 확인합니다. 이 학습 페이지에서는 모의투자계좌 행의 키만 사용하고, 아래 값은 이 프로젝트의 .env에만 입력합니다.

# KIS 모의투자 전용 — .env (Git에 커밋하지 않음)
KIS_MODE=mock
KIS_APP_KEY=발급받은_모의_APP_KEY
KIS_APP_SECRET=발급받은_모의_APP_SECRET
KIS_ACCOUNT_NO=모의계좌_앞_8자리
KIS_ACCOUNT_PRODUCT_CODE=01

이 프로젝트의 .gitignore에는 이미 .env, .env.* 제외 규칙이 설정되어 있습니다. 새 비밀값 파일을 만들었다면 같은 규칙에 포함되는지 확인하고, 공유용 예시는 값이 비어 있는 .env.example만 사용하세요.

# .gitignore — 실제 비밀값 파일은 Git에서 제외
.env
.env.*
!.env.example
공유 금지: App Key·App Secret·접근 토큰·계좌번호가 포함된 .env, 캡처 이미지, 로그를 Git·메신저·이메일·브라우저 코드에 올리지 마세요. 이미 노출됐다면 해당 키를 폐기하거나 재발급하고, 노출된 저장소 이력도 즉시 점검하세요.

Python 서버에서는 환경변수로부터만 읽고, 요청마다 모의 설정을 검증합니다. 토큰은 응답 본문이나 애플리케이션 로그에 남기지 않습니다.

import os

KIS_MODE = os.environ.get("KIS_MODE", "mock")
if KIS_MODE != "mock":

KIS_ACCOUNT_PRODUCT_CODE = os.environ.get("KIS_ACCOUNT_PRODUCT_CODE", "01")
PART 5 · 인증과 주문 구현

토큰 → 조회 → 최소 주문 순서로 검증합니다

개인·일반법인 API는 Client Credentials 방식으로 접근 토큰을 발급받습니다. KIS 공식 문서상 토큰 유효기간은 24시간이므로, 응답의 만료시각을 저장해 불필요한 재발급을 피하세요.

import requests

def get_access_token():
    response = requests.post(
        f"{KIS_BASE_URL}/oauth2/tokenP",
        headers={"content-type": "application/json; charset=utf-8"},
        json={"grant_type": "client_credentials",
              "appkey": KIS_APP_KEY,
              "appsecret": KIS_APP_SECRET},
        timeout=10,
    )
    response.raise_for_status()
    return response.json()["access_token"]  # 안전한 서버 저장소에만 보관
def order_mock_buy(access_token, stock_code="005930", qty=1, price=0):
    order_type = "01" if price == 0 else "00"  # 01: 시장가, 00: 지정가
    response = requests.post(
        f"{KIS_BASE_URL}/uapi/domestic-stock/v1/trading/order-cash",
        headers={"content-type": "application/json; charset=utf-8",
                 "authorization": f"Bearer {access_token}",
                 "appkey": KIS_APP_KEY, "appsecret": KIS_APP_SECRET,
                 "tr_id": "VTTC0012U", "custtype": "P"},
        json={"CANO": KIS_ACCOUNT_NO, "ACNT_PRDT_CD": KIS_ACCOUNT_PRODUCT_CODE,
              "PDNO": stock_code, "ORD_DVSN": order_type,
              "ORD_QTY": str(qty), "ORD_UNPR": str(price),
              "EXCG_ID_DVSN_CD": "KRX"},
        timeout=10,
    )
    response.raise_for_status()
    result = response.json()
    if result.get("rt_cd") != "0":
        raise RuntimeError(f"KIS 주문 거절: {result.get('msg_cd')} {result.get('msg1')}")
    return result
주문 API의 필수·선택 필드, 거래소 구분 및 거래 ID는 상품·API 버전에 따라 달라질 수 있습니다. 위 예시는 현재 공식 저장소의 국내주식 order_cash 구조를 학습용으로 단순화한 것입니다. 구현 전에 KIS Developers의 해당 API 문서에서 요청·응답 명세와 오류 코드를 다시 확인하세요.

연결 테스트 기록 · 읽기 전용

모의투자 키로 국내주식 현재가를 확인하는 절차

이 프로젝트에서는 python-stock-backend/kis_quote_test.py로 삼성전자(005930) 현재가를 테스트했습니다. 이 스크립트는 kis.key 또는 서버 환경변수의 App Key·Secret을 읽되, 키·토큰·계좌번호를 출력하거나 저장하지 않습니다.

순서테스트 내용결과 및 조치
1키 유형 확인실전 도메인 호출은 모의투자 App Key로 허용되지 않아 EGW02004로 거부됐습니다. 이 결과로 현재 키가 모의투자용임을 확인했고, 이후 실전 도메인을 사용하지 않습니다.
2모의 Testbed 선택https://openapivts.koreainvestment.com:29443에서 /oauth2/tokenP 토큰을 발급한 뒤, /uapi/domestic-stock/v1/quotations/inquire-price에 tr_id=FHKST01010100, FID_COND_MRKT_DIV_CODE=J, 종목코드를 전달합니다.
3토큰 발급 제한 확인모의투자 토큰은 1분당 1회만 발급할 수 있습니다. 제한 시간 안에 다시 발급하면 EGW00133과 함께 잠시 후 재시도하라는 응답이 돌아옵니다. 토큰은 만료시각까지 서버에 캐시하고, 테스트 때도 1분 이상 간격을 둡니다.
4시세 응답 확인최종 Testbed 요청에서는 네트워크 읽기 시간 초과가 발생해 가격 응답을 받지 못했습니다. 토큰을 반복 발급하지 말고 1분 제한이 지난 뒤 한 번만 재시도하며, timeout=15·지수 백오프를 적용합니다.

PART 7 · MCP · VS Code

MCP로 VS Code에서 자연어로 KIS API 사용하기

위 broker-api-test.html 연결 테스트와는 별개로, 한국투자증권이 공식 배포하는 MCP(Model Context Protocol) 서버를 VS Code(GitHub Copilot Chat 에이전트 모드)·Claude Desktop·Cursor에 연결하면 자연어로 KIS Open API를 호출할 수 있습니다. 이 프로젝트의 broker_test.py를 감싼 것이 아니라, 한투 공식 저장소의 MCP/Kis Trading MCP 서버를 별도로 clone해 그대로 사용합니다. 국내·해외 주식, 선물옵션, 채권, ETF 등 166개 API를 도구로 제공합니다.

1

공식 MCP 서버 clone과 의존성 설치

저장소 루트에서 실행합니다. 이 clone은 이 프로젝트의 Git 이력에 포함되지 않습니다(.gitignore의 /mcp/). Python 3.11+와 uv가 필요합니다.

2

모의투자 키 재사용

이미 발급받은 kis.key의 모의 App Key·Secret을 그대로 재사용합니다. 실전 키는 설정하지 않아 실전 거래 도구는 비활성 상태로 남습니다.

3

.vscode/mcp.json에 서버 등록

계좌번호는 저장소 어디에도 저장하지 않고, VS Code가 서버를 처음 실행할 때 안전한 입력창(inputs)으로 물어보도록 구성합니다.

4

Copilot Chat 에이전트 모드에서 사용

워크스페이스를 열고 계좌번호를 입력하면, 채팅에서 자연어로 시세·잔고 조회를 요청할 수 있습니다.

  }
}
ENV=live는 실전 거래를 뜻하지 않습니다 — MCP 서버가 로드할 전송 설정 파일(.env.live) 이름일 뿐이며, 실전·모의 구분은 KIS_APP_KEY(실전, 비워둠) 대 KIS_PAPER_APP_KEY(모의, 설정함)로 결정됩니다.

사용: VS Code에서 이 워크스페이스를 열고 Copilot Chat을 에이전트 모드로 전환하면 계좌번호 입력 프롬프트가 표시됩니다. 이후 채팅에서 자연어로 질문합니다.

질문 예시호출되는 영역
"삼성전자 현재가 조회해줘"국내주식 시세
"모의투자 계좌 잔고 보여줘"계좌·잔고
"KODEX 200 ETF NAV 비교추이 확인해줘"ETF/ETN
중요: 실전 거래용 KIS_APP_KEY/KIS_APP_SECRET는 설정하지 마세요. 설정하는 순간 MCP 도구가 실제 자금으로 주문을 실행할 수 있습니다. 이 페이지의 구성은 모의투자 전용입니다.
