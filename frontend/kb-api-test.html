KB증권 Open API 연결 테스트

서버만 프로젝트 루트의 kb.key 또는 서버 환경변수에서 App Key·Secret을 읽습니다. 브라우저에는 Key·Secret·Access Token을 보내지 않으며, 이 페이지는 주문·정정·취소를 실행하지 않습니다.

점검 순서: 먼저 토큰 발급을 1회 확인한 뒤 현재가·종목정보·호가·일봉을 한 항목씩 조회합니다. KB B2C Open API는 운영 환경이므로 모든 요청은 실제 시세 조회이며, 이 화면은 주문·잔고 조회를 제공하지 않습니다.
