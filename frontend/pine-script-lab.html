Pine Script 간단 테스트

예제 코드를 수정해 이동평균·RSI 신호와 간단한 과거봉 시뮬레이션을 확인합니다. 이 화면은 TradingView 서버나 계좌에 연결되지 않으며, 주문을 만들지 않습니다.

중요: 실제 Pine Script 컴파일·차트 적용·Strategy Report는 TradingView Pine Editor에서 수행합니다. 이 도구의 계산 결과는 학습용 비교 값이며 실제 체결·수수료·슬리피지를 반영하지 않습니다.
1. 예제 선택아래의 MA 교차 예제를 먼저 누릅니다.
2. 코드 확인검은 입력창에 코드가 채워졌는지 확인합니다.
3. 테스트 실행문법·전략 테스트를 누릅니다.
4. 결과 읽기오른쪽의 신호·수익률·낙폭을 비교합니다.

TradingView에서 최종 확인할 항목

  • 차트·시간봉·데이터 공급자를 정한 뒤 Pine Editor에 같은 코드를 넣고 Add to chart를 선택합니다.
  • Strategy Report에서 순이익만 보지 말고 거래 수, 최대 낙폭, 수수료·슬리피지 가정과 개별 거래를 함께 확인합니다.
  • 실시간 봉은 마감 전 값이 바뀔 수 있습니다. 재도색 가능성, 알림 중복, 실제 주문 실패 처리는 별도로 설계합니다.
