OHLCV Open API 사용 명세서

pg-stock에 일별로 수집된 국내주식 OHLCV를 외부 프로그램과 브라우저에서 읽기 전용으로 조회합니다. 종목 검색 후 연도 또는 날짜 범위로 일봉을 가져오며, 별도 API Key나 로그인 없이 누구나 호출할 수 있는 완전 공개 API이며, CORS 프록시도 필요 없습니다.

이 API의 Python 백엔드 프레임워크와 저장소 구조

이 API는 Lambda 함수가 아닙니다. Docker 컨테이너에서 계속 실행되는 Python 3.11 · Flask WSGI 애플리케이션이며, Nginx가 요청을 Gunicorn으로 전달하고 Flask Blueprint가 PostgreSQL을 조회합니다.

Web FrameworkFlask 3.0.3

app.py가 애플리케이션을 만들고 openapi.py Blueprint를 등록합니다.

WSGI ServerGunicorn 23.0.0

1 worker · 8 threads로 8200 포트에서 장기 실행합니다. 요청마다 프로세스가 생기는 Lambda 구조가 아닙니다.

DB ToolkitSQLAlchemy 2.0.35

ORM 모델 대신 text() SQL과 Engine/Connection API로 OHLCV를 읽습니다.

PostgreSQL Driverpsycopg 3.2.3

psycopg[binary]가 SQLAlchemy와 pg-stock:5432 사이의 실제 DB 통신을 담당합니다.

Cross OriginFlask-CORS 4.0.1

/openapi/*에는 모든 Origin, GET/POST/OPTIONS와 표준 헤더를 허용합니다.

Container RoutingNginx + Docker Compose

Nginx의 /openapi/ 프록시가 python-backend:8200으로 전달하고 백엔드는 postgresql_default 네트워크의 pg-stock을 조회합니다.

Flask 애플리케이션에 Blueprint 연결 · app.py
# python-stock-backend/app.py
from flask import Flask
from flask_cors import CORS
from openapi import open_api_bp

app = Flask(__name__)
CORS(app, resources={"/openapi/*": {
    "origins": "*",
    "supports_credentials": False
}})
app.register_blueprint(open_api_bp)
Blueprint에서 PostgreSQL 조회 · openapi.py
# python-stock-backend/openapi.py
open_api_bp = Blueprint(
    "openapi", __name__, url_prefix="/openapi/v1"
)

@open_api_bp.get("/ohlcv/<ticker_code>")
@public_endpoint
def ohlcv_history(ticker_code):
    with get_ohlcv_engine().connect() as conn:
        rows = conn.execute(text(SQL), params)
    return jsonify({"rows": _result_rows(rows)})
컨테이너 시작 명령gunicorn --bind 0.0.0.0:8200 --workers 1 --threads 8 --timeout 120 app:app
DB 연결 문자열postgresql+psycopg://admin:admin1234@pg-stock:5432/admin

왜 worker가 1개인가? 현재 공개 요청 제한 bucket이 openapi.py의 프로세스 메모리에 있습니다. worker를 여러 개로 늘리면 제한 상태가 나뉘므로, 다중 worker로 확장할 때는 Redis 기반 rate limiter로 옮겨야 합니다.

01

키 없이 바로 호출

인증 없이 누구나 호출할 수 있는 완전 공개 API입니다. 키·토큰·로그인이 필요 없습니다.

1. 종목 탐색

/ohlcv/tickers에서 제공 종목과 데이터 기간을 확인합니다.

2. 일봉 조회

/ohlcv/{ticker}를 연도·날짜·페이지 조건과 함께 호출합니다.

3. 인증 없음

Authorization 헤더나 키 없이 그대로 요청합니다.

4. 페이지 반복

응답의 nextOffset으로 다음 페이지를 이어서 조회합니다.

가장 작은 GET 요청
GET https://<서비스 도메인>/openapi/v1/ohlcv/tickers?year=2026
CORS 기본 제공
응답에 Access-Control-Allow-Origin: *가 적용되고, preflight는 Content-Type 등 표준 헤더를 허용합니다. 인증 헤더가 필요 없습니다. 외부 브라우저 앱에서 별도 CORS 설정이나 중계 서버 없이 호출할 수 있습니다.
