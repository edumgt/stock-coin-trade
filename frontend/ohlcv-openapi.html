OHLCV Open API 사용 명세서

pg-stock에 일별로 수집된 국내주식 OHLCV를 외부 프로그램과 브라우저에서 읽기 전용으로 조회합니다. 종목 검색 후 연도 또는 날짜 범위로 일봉을 가져오며, 별도 CORS 프록시 없이 사용할 수 있습니다.

인증과 기본 호출 흐름

모든 OHLCV 요청에 동일한 Bearer API Key를 사용합니다.

1. 키 발급

로그인 후 API Key 관리 화면에서 키를 생성합니다. 원문은 생성할 때 한 번만 표시됩니다.

2. 헤더 설정

Authorization: Bearer <API_KEY>를 요청마다 전송합니다.

3. 종목 탐색

/ohlcv/tickers에서 제공 종목과 데이터 기간을 확인합니다.

4. 일봉 조회

/ohlcv/{ticker}를 연도·날짜·페이지 조건과 함께 호출합니다.

GET https://<서비스 도메인>/openapi/v1/ohlcv/tickers?year=2026
Authorization: Bearer eduapi_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
CORS 기본 제공
응답에 Access-Control-Allow-Origin: *가 적용되고, preflight는 Authorization과 Content-Type 헤더를 허용합니다. 외부 브라우저 앱에서 별도 CORS 설정이나 중계 서버 없이 호출할 수 있습니다.
GET

제공 종목 탐색

검색 조건에 맞는 종목과 실제 적재 기간을 페이지 단위로 반환합니다.

GET/openapi/v1/ohlcv/tickers읽기 전용 · API Key 필수
파라미터위치형식·기본값설명
qQuerystring · 선택종목 코드 또는 종목명 부분 검색
marketQuerystring · 선택KOSPI, KOSDAQ 등 시장 완전 일치
yearQuery1990~내년 · 선택해당 연도 데이터가 존재하는 종목만 조회
limitQuery1~200 · 기본 100한 페이지의 최대 종목 수
offsetQuery0 이상 · 기본 0건너뛸 종목 수

호출 예시

curl "https://<서비스 도메인>/openapi/v1/ohlcv/tickers?q=삼성&market=KOSPI&year=2026&limit=20" \
  -H "Authorization: Bearer <API_KEY>"

응답 예시

{

종목별 일봉 OHLCV 조회

한 종목의 일봉을 연도 또는 날짜 구간으로 조회합니다.

GET/openapi/v1/ohlcv/{ticker_code}읽기 전용 · API Key 필수
파라미터위치형식·기본값설명
ticker_codePath1~20자 · 필수예: 005930. 영문·숫자·점·밑줄·하이픈 허용
yearQuery1990~내년 · 선택연도 범위. 날짜와 함께 쓰면 해당 연도 안에서 교집합 적용
date_fromQueryYYYY-MM-DD · 선택조회 시작일 포함
date_toQueryYYYY-MM-DD · 선택조회 종료일 포함
orderQueryasc | desc · 기본 asc거래일 정렬 방향
limitQuery1~1000 · 기본 250한 페이지의 최대 일봉 수
offsetQuery0 이상 · 기본 0건너뛸 행 수

호출 예시

curl "https://<서비스 도메인>/openapi/v1/ohlcv/005930?year=2026&order=asc&limit=250" \
  -H "Authorization: Bearer <API_KEY>"

// Browser
fetch(`${base}/openapi/v1/ohlcv/005930?year=2026`, {
  headers: { Authorization: `Bearer ${apiKey}` }
}).then(response => response.json())
