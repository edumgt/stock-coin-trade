실행설명 — 이 표의 작업은 개발자가 직접 하며, working/scripts/graft-target.sh 가 그 역할을 대신합니다

그 표의 다섯 항목은 개발자가 직접 손으로 바꾸는 작업입니다. 다만 표 자체는 "무엇이 왜 달라지는지"를 이해시키는 설명이고, 실제 작업은 바로 다음 STEP 3 의 명령어들이 그대로 수행합니다.

STEP 3 에서 각 항목이 어떻게 처리되는지
  • 핸들러 파일과 requirements 는 cp 명령 한 줄로 quant/ 폴더에 복사됩니다. 코드를 새로 쓰는 것이 아니라 working/lambda/quant 의 파일을 그대로 가져오는 것입니다.
  • 이벤트 파일도 cp 로 events/quant.json 에 복사됩니다.
  • Handler, CodeUri, 환경변수, HttpApi 경로는 모두 template.yaml 안의 값이므로, STEP 3 의 "template.yaml (전체 교체)" 창 내용을 복사 버튼으로 붙여 넣으면 한 번에 반영됩니다.
  • env.json 도 같은 방식으로 붙여 넣고 계정만 채웁니다.

즉 개발자가 실제로 타이핑하는 것은 명령어 몇 줄과 파일 두 개 붙여 넣기이고, 표는 그 붙여 넣기가 Hello World 의 무엇을 대체하는지 알려 주는 대조표입니다.

왜 자동화하지 않았는지
  • SAM 은 프로젝트 골격만 만들어 주고, 어떤 코드를 어떤 경로에 붙일지는 개발자의 설계 영역이라 도구가 대신 정하지 않습니다.
  • 학습 목적으로는 Handler 와 CodeUri 가 어떻게 연결되는지 직접 바꿔 보는 것이 이해에 도움이 됩니다. SAM 활용 1 의 오류 대부분이 이 연결 실수에서 나옵니다.
반복이 번거로우면 두 가지 대안이 있습니다
  • working/scripts 방식(STEP 7 대안)은 복사 없이 저장소 템플릿을 그대로 빌드·호출하므로 이 표의 작업이 필요 없습니다. 대신 템플릿에 로컬 변수 선언을 추가해야 하는 문제는 남아 있습니다.
  • working/scripts/graft-target.sh <target> <project-dir> 가 이 다섯 항목을 한 번에 수행합니다. 타깃 이름만 주면 [1] 코드 복사 → [2] 이벤트 복사 → [3] template.yaml 생성 또는 함수 블록 추가(Handler·CodeUri·환경변수 선언·HttpApi 경로) → [4] env.json 병합까지 끝나므로, member·session 으로 확장할 때도 같은 한 줄로 됩니다. 아래는 새 프로젝트 sam-app-03 에 quant 와 member 를 차례로 이식하고 빌드·호출까지 실제로 실행한 기록입니다. env.json 의 USER:PASSWORD 만 직접 채웁니다.

직접 수정 ② template.yaml (전체 교체) — 스크립트를 안 썼을 때
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Description: sam-app-02 — working/lambda/quant 를 이식한 Quant DB 최근 시세 조회 Lambda

Parameters:
  QuantSecretArn:
    Type: String
    Default: ''
    Description: QUANT_DATABASE_URL 키를 가진 Secrets Manager secret ARN (로컬에서는 비워 둠)

Globals:
  Function:
    Timeout: 15
    MemorySize: 512

Resources:
  QuantPricesFunction:
    Type: AWS::Serverless::Function
    Properties:
      CodeUri: quant/                        # working/lambda/quant 에서 복사한 폴더
      Handler: lambda_quant.lambda_handler   # quant/lambda_quant.py 의 lambda_handler
      Runtime: python3.12                    # 로컬 WSL Python 과 같은 버전
      Architectures: [x86_64]
      Environment:
        Variables:
          QUANT_SECRET_ARN: !Ref QuantSecretArn
          QUANT_DATABASE_URL: ''               # 로컬 전용: env.json 이 이 값을 덮어씀 (템플릿에 선언돼야 전달됨)
      Events:
        QuantPrices:
          Type: HttpApi
          Properties:
            Path: /quant/prices
            Method: GET

Outputs:
  ApiUrl:
    Value: !Sub 'https://${ServerlessHttpApi}.execute-api.${AWS::Region}.${AWS::URLSuffix}/quant/prices'
  FunctionArn:
    Value: !GetAtt QuantPricesFunction.Arn
