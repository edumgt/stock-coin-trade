Binance Spot 심볼·시세 조회

역할: 거래 가능한 Spot 심볼을 검색하고 공개 시세와 호가를 조회합니다.

심볼 구성

기준 자산과 결제 자산을 붙입니다. BTC + USDT는 BTCUSDT입니다.

검색 방법

BTC, ETH 또는 전체 심볼 BTCUSDT를 입력합니다.

조회 범위

현재 거래 상태가 TRADING인 Binance Spot 심볼만 표시합니다.

심볼 찾기

코인 또는 거래쌍을 검색하고 결제 자산으로 결과를 좁힐 수 있습니다.

심볼 목록을 불러오는 중…

시세·호가 조회

검색 결과를 선택하거나 심볼을 직접 입력하세요.

24시간 시세현재가, 등락률, 고가·저가와 거래량을 확인합니다.
호가 10단계매수·매도 대기 가격과 수량을 10단계까지 확인합니다.
슬래시 없이 대문자로 조회합니다. 예: BTC/USDT → BTCUSDT. API Key는 필요하지 않으며 주문 기능은 제공하지 않습니다.
