한국투자증권 KIS Open API 연결 테스트

KIS 모의투자(Testbed)의 국내주식 시세·일봉·호가·잔고·시장지수를 점검합니다. 인증정보는 서버에서만 읽으며 브라우저에는 App Key·Secret·계좌번호·접근 토큰을 전달하지 않습니다.

호출 경로: 브라우저 → 이 저장소 백엔드 /api/broker-test/kis/quote·chart·orderbook·index·balance → KIS Testbed quotations/inquire-price 등 5개 조회 API. 브라우저가 KIS 를 직접 호출하지 않으며 키·토큰은 백엔드에만 있습니다. 자세한 표는 3단계 · 테스트의 "호출 경로" 참고.

1. KIS 모의투자 키 준비KIS Developers에서 모의투자 App Key와 App Secret을 발급받습니다. 실전투자 키가 아닌 모의투자용 키를 사용하세요.
2. 서버에 인증정보 저장프로젝트 루트의 kis.key에 App-KEY, Secret, account=CANO-상품코드를 저장합니다. 시세 조회만 할 때는 account를 생략할 수 있습니다.
3. 백엔드 실행 후 조회docker compose up -d --build로 서비스를 실행합니다. 아래에 6자리 KRX 종목코드를 입력하고 필요한 조회 버튼을 한 번씩 누릅니다.
테스트 전 확인
  • 이 화면은 조회 전용이며 주문·정정·취소 API를 호출하지 않습니다.
  • 접근 토큰은 서버에서 재사용합니다. 버튼을 빠르게 연속 클릭하지 마세요.
  • 잔고 조회에는 kis.key의 account=CANO-상품코드 또는 .env의 KIS_ACCOUNT_NO가 필요합니다.
  • 권장 순서: 현재가 → 일봉·호가 → 지수 → 잔고. 주문·정정·취소는 모의 주문 흐름 테스트에서만 실행합니다.
  • 모의투자 시세와 거래량은 실전 시세와 다를 수 있습니다.
