# S3 세 기능 연결 — 설계

- 작성: 2026-09-26, PM 에이전트(Claude Code)
- 상위 계획: 서비스 고도화 프로그램. 앞 단계는 S1 계정·신뢰(`2026-09-26-s1-account-trust-design.md`)와 S2 데이터 권한(`docs/evidence/data-rights-2026-09-26.md`)이다.
- 상태: 노아 지시 "6단계 쭉 진행"(2026-09-26)에 따라 PM이 정했다. 비용이 드는 결정(AI 공개)은 노아 확인 항목으로 남긴다.

## 쉬운 요약 (노아용)

세 기능은 "공시를 보고 → 아이디어를 백테스트로 확인하고 → 근거를 AI에게 묻는다"로 이어집니다.

1. **공시 알림을 공개합니다.** 금융감독원 DART 공시 목록과 유형·위험 표시를 로그인 없이 볼 수 있게 합니다.
   - 공개 조건(노아 판정 2026-09-26)대로 출처와 "정확성은 보장하지 않음"을 붙입니다.
   - **내 관심 종목의 공시**를 따로 모아 봅니다. 관심 종목은 지금처럼 방문자의 브라우저에만 있으므로 새로 모으는 개인정보가 없습니다.
2. **공시에서 바로 백테스트로 갑니다.** 공시 줄마다 "이 종목 백테스트" 링크를 둡니다.
   - 공개 사이트의 백테스트는 합성 학습 데이터라는 표시를 유지합니다(유료 시세를 사지 않기로 한 결정).
3. **AI 질문은 준비만 합니다.** 미국 전송 동의와 인증 회원 제한을 붙여 두되, 공개 사이트에서 켜는 것은 월 예산을 노아가 정한 뒤입니다.

노아가 하실 일
- OpenDART 인증키를 공개 서버에 넣는 것(키 값은 저를 거치지 않게 `!` 명령으로 직접 넣으시면 됩니다)
- 나중에: AI 질문 공개 여부와 월 예산

## 범위

| 포함 | 제외(이유) |

## 설계

### ① 공시 공개
- `config/data_sources.toml`의 `dart.enabled.public`을 `true`로 바꾼다. 이렇게 하면 `dart_bp`가 공개 프로필에도 등록되고, worker 수집은 `DART_API_KEY`가 있을 때만 돈다.
- 인증키는 SSM `/stock-coin-trade/prod/dart-api-key`(SecureString)에 둔다. 배포 스크립트는 이 값을 `DART_API_KEY`로 넘긴다(파라미터 이름 규칙). 약관 제19조②에 따라 인증키를 제3자에게 넘기지 않는다. 서버 안에서만 쓰고, 화면과 로그에는 내보내지 않는다.
- 고지(약관 제23조① 정확성 비보장)
  - `events.html` 하단에 "DART 자료의 정확성·완전성은 금융감독원과 이 서비스 모두 보장하지 않습니다. 투자 판단의 근거로 쓰기 전에 원문을 확인하세요."를 추가한다.
  - API 응답의 `notice`에도 같은 취지를 넣는다.
- 판정은 지금처럼 규칙이 먼저 하고, 규칙이 못 정한 것만 판정 모델이 정한다. 판정 모델에는 공시 제목·비고·시장만 가고 회사명은 가지 않는다. 개인정보가 없으므로 동의가 필요 없다(처리방침 4절의 명령 바 전송과는 별개).

### ② 관심 종목 공시
- `GET /api/disclosures?symbols=005930,000660`: 쉼표로 여러 종목(최대 20개, 각 6자리)을 받아 최근 30일 공시를 준다. `symbol` 하나는 지금처럼 유지한다.
- `events.html`에 "내 관심 종목" 버튼을 둔다. 주식 화면이 쓰는 `localStorage.stockWatchlist`를 읽어 요청하고, 비어 있으면 "주식 화면에서 ★로 관심 종목을 추가하세요"를 보여 준다.
- 서버에는 관심 종목을 저장하지 않는다. 새 개인정보가 없다.

### ③ 공시 → 백테스트
- 공시 줄의 종목코드 옆에 `/quant.html?symbol=005930` 링크("백테스트")를 둔다. 퀀트 화면이 `symbol` 쿼리를 이미 받는지 확인하고, 받지 않으면 폼에 채우는 코드를 더한다.
- ~~공개 사이트의 백테스트는 합성 데이터라는 표시가 이미 있다. 링크를 따라가도 그대로 보인다.~~
  - **정정(2026-09-27)**: 사실이 아니었다. 합성이라는 표시는 API 응답과 영수증의 `sources`에만 있었고, 화면에는 없었다.
  - PR #43에서 백테스트 결과 위에 "합성 데이터 · 실제 시세 아님" 배지를 붙였다. 첫 화면과 퀀트 화면에도 표시를 더했다.
  - 링크는 데이터가 있는 종목에만 단다. 기준은 `/api/quant/overview`의 `backtestable`이다(노아 결정 (가)).
  - 기록: `docs/evidence/verify-followup-2026-09-27.md`.

### ④ AI 질문 준비(공개는 노아 결정 뒤)
- `/api/agent/ask`는 **현재 처리방침 버전 동의(`consent`)**를 확인한다. 질문이 미국 Anthropic으로 가는 국외 이전이다(명령 바와 같은 방식).
  - 동의가 없으면 Anthropic을 부르지 않고, 초대 코드 한도도 쓰지 않고 `consentRequired`로 답한다.
  - (구현 때 판단) 인증 회원 제한은 따로 두지 않는다. 메일 인증 모드에서는 인증 전 로그인 자체가 막혀 이 API에 닿을 수 없다. S1 스펙 "AI 질문은 인증 후"는 이것으로 충족된다.
- 처리방침 4절에 AI 질문 항목을 더하되, 공개 사이트에서 `AI_ENABLED`가 꺼져 있는 동안은 "현재 공개 사이트에서는 쓰지 않음"으로 적는다.
- 사용 한도는 기존 초대 코드별 한도와 월 예산 원장(`ai_usage`)을 그대로 쓴다. 회원별 하루 한도는 공개를 켤 때 노아가 정한 예산으로 정한다.

## 검증
- **단위**
  - `symbols` 파싱(최대 20개, 형식 오류 400, 중복 제거)
  - AI 질문의 동의 전 미호출·한도 미차감(통합)
- **통합**: `symbols`로 두 종목 공시를 함께 받는다(실제 MariaDB).
- **검증 스킬**: F5 공시 기능 지도를 새로 만든다(T0 스펙 "F3~F5는 그 기능을 고칠 때 추가").
  - 공시 목록 API와 관심 종목 요청을 확인한다.
  - 화면은 쿠키 없는 Playwright로 확인한다.
- **공개 배포 뒤**
  - `/api/disclosures`가 200이고 출처와 고지 문구가 붙는지 확인한다.
  - worker가 수집 작업을 등록했는지 확인한다. 키가 없으면 "미등록"이 정상이다.
- **교차 검토**: OpenCode(GPT 계열)와, 10-01 한도가 풀린 뒤에는 Codex를 쓴다. 새 Claude 보안 검토자도 함께 쓴다.
